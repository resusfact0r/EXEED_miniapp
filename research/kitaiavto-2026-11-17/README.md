## Правила переноса и поведение сайта

- Совпадает весь номер с суффиксом. В записи источника разрешено убрать только форматирующие дефисы и пробелы; неоднозначные совпадения наших номеров исключаются. В приложении разрешённый список ищется по точному нашему коду.
- Для каждой добавленной связи есть нумерованная строка полученной схемы и соответствующая ссылка в sitemap. Аналоги, копии, похожие номера и коды семейств автомобилей не превращаются в новые связи.
- Сохраняются отдельные FL, рестайлинги, Pro/Max, годы в обозначении модели, а также конфигурация двигателя и коробки. Утверждения «подходит ко всем годам/двигателям» не создаются.
- Для обогащённых артикулов марки и модели берутся из принятого списка, чтобы общее название поставщика не расширяло, например, VX FL до VX. Для остальных работает прежняя текстовая навигация.
- Новые модели участвуют в фильтрах и строке поиска. Поисковые слова из разных записей источника не объединяются в выдуманную пару марки и модели.
- В карточке есть раскрываемый список «Марки и модели» с исполнением и ссылкой «Схема». Источник явно указан как каталог **КитайАвто**. Это сведения указанного продавца, а не наше подтверждение применяемости по VIN; перед заказом сохраняется проверка по VIN.

Проверка касается наличия номера в явно указанном модельном каталоге. Получение дилерской VIN-выгрузки и проверка фактической установки детали на автомобиле в неё не входят. Дата проверки означает дату обращения к источнику, а не дату его обновления производителем.

При выборочной проверке обозначений использованы также официальные спецификации: [Tiggo 8 Pro Max, включая 1.6T](https://www.chery.ru/tiggo_8_pro_max_new_dec_07.12_2024_4080622804507592131.pdf), [OMODA S5 GT 1.5T CVT](https://files.omoda.ru/priceS5gt.pdf). Их наличие не расширяло список номеров деталей.

## Данные и воспроизведение

[evidence.json](evidence.json) содержит полученные номера и позиции строк, заголовки схем, подтверждающие URL, хеши sitemap и коды действующего каталога. Полные HTML, рисунки, фотографии, чужие цены и остатки не копируются в приложение.

Рабочий разрешённый список — [article-applications.json](../../server/src/catalog/article-applications.json). Его можно воспроизвести без сети:

```sh
python scripts/build-article-applications.py
python scripts/build-article-applications.py --check
```

Сборка сайта использует сохранённый список; автоматического сбора новых применяемостей при импорте цен или запуске сервера нет. В рабочую БД дополнительные записи не вносились: одна таблица навигации используется API и генератором резервного каталога.

Локально пройдены **58 автоматических проверок**: 16 unit, 1 запуск собранных модулей, 5 backend, 27 браузерных сценариев и 9 проверок механизма развёртывания. До изменения было 13 386 товаров без марки, после — 12 394. Суммировать количества по маркам нельзя: одна деталь встречается у нескольких марок.

В Chrome проверены мобильная карточка с источником, выбор новых моделей, поиск, корзина, шесть размеров экрана и доступность. Скриншот новой карточки просмотрен вручную. Автоматические тесты проверяют работу приложения и происхождение данных; они не заменяют VIN-подбор.
