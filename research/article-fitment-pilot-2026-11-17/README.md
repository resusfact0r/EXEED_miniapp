# Поиск применяемости по 100 артикулам — 17 ноября 2026

Проверены 100 разных артикулов из действующего каталога https://exeedbot.ru. Для каждого выполнен отдельный поиск точного номера в кавычках. По 87 артикулам поиск вернул страницы, по 13 результатов для использованного запроса не было. Это **результат поиска, а не 87 подтверждённых применяемостей**.

**Повторная проверка перед переносом в сайт: 0 новых связей допущено, 100 отложено.** По строгому требованию владельца имеющихся доказательств недостаточно. Причины и решение по каждому номеру: [IMPORT-REVIEW.md](IMPORT-REVIEW.md) и [import-review.json](import-review.json). Текущая работа сайта не изменена.

Выборка охватывает восемь разделов: по 12 позиций из объединённых пулов первой, средней и последней страниц каждого раздела, с удалением дублей. Оставшиеся четыре позиции — два обсуждавшихся артикула и два дополнительных товара из того же каталога. Выбирались номера не короче шести символов; короткие магазинные артикулы в этот прогон не входили. На момент получения данных в действующем каталоге было 13 632 позиции. Это исследовательская выборка, по ней нельзя обещать такой же процент находок для всего каталога.

## Сверка с документом Chery

Найден публично размещённый документ производителя **CHERY T1E Labour Time Manual 2020**, содержащий нормы времени и номера деталей. Введение ограничивает область документа моделью T1E и сочетаниями E4T15C+CVT25, E4T15C+6MT, F4J16+7DCT.

Из исследуемых 100 артикулов в документе найдены `155000158AA` на странице PDF 137 и `302000129AA` на странице PDF 103. Совпадения номеров подтверждают их наличие в документе указанной области; они не доказывают применяемость ко всем годам и рынкам семейства Tiggo 7.

[Источник документа](https://omoda-club.ru/attachments/Каталог-запчастей-chery-tiggo-7-pro-pdf.1180/). Копия PDF и его полный текст в ветку не включены.

## Что отбрасывать при автоматическом сборе

- В поиске по `206000119AB` найдена карточка Allegro с J5/J7/OMODA 5 в названии, но точный номер в открытой странице не найден. Эти модели не приняты в список проверенных связей из этой карточки.
- У `204000470AA` заголовок коллекции называет товар болтом, а исходное название и объявления описывают пружину/скобу колодок. Тип детали нельзя брать из общего заголовка коллекции.
- На страницах встречаются другие номера, блоки аналогов, соседние товары и автомобильные категории. Наличие модели где-либо на странице не означает применяемость запрошенного номера.
- Городские версии одного каталога и копии одного объявления не считаются независимыми подтверждениями.
- Производитель детали хранится отдельно от марки автомобиля. Полный номер и суффикс сохраняются; кросс, аналог и совпадение базовой части номера не равны одной детали.

## Как использовать результат

Для будущего каталога нужна связь многие-ко-многим: одна деталь — несколько автомобилей, один автомобиль — несколько деталей. У каждой связи должны быть источник, дата, тип доказательства и статус проверки; рынок, двигатель, коробка, годы и рестайлинг уточняются отдельно.

По указанию владельца для VX FL (`M36TFL`) сохраняется **модельный год 2024+**. Это правило справочника не добавляет каждому найденному артикулу автоматическую совместимость со всеми VX.

Кандидаты из поисковых заголовков отделены от заявлений, просмотренных на странице, и от совпадений в документе производителя. Результаты этой выборки не импортировались в рабочую БД и не меняют фильтры сайта.

## Файлы

- [articles.csv](articles.csv) — 100 строк для просмотра в таблице, UTF-8 с BOM. Столбец артикула при импорте в Excel следует читать как текст.
- [evidence.json](evidence.json) — номера, наши исходные названия, URLs результатов, непроверенные упоминания моделей, отдельные проверенные заявления продавцов и ссылки на документ Chery.

В CSV включены URLs результатов с точным упоминанием номера и ссылки разобранных примеров. В JSON сохранены также остальные поисковые результаты с флагом `articleMentionedInSearchResult: false`, чтобы можно было проверить отбраковку нерелевантных страниц.

Отсутствие результата в этой выборке означает только отсутствие находки по конкретному запросу. Это не утверждение, что данных об артикуле нет в других каталогах.
